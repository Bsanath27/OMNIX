## 4. Architectural Rules Established

1. **Clean Global Navigation (R1):** Primary navigation sidebar is strictly limited to 4 universal destinations (`Home`, `Tools`, `Library`, `Settings`). All project lists, file upload buttons, and passage snippets are relocated out of the primary sidebar.
2. **Pedagogical Workspace Separation (R2):** Chapter project lifecycle and passage inspection belong in the dedicated Library view as a full 2-column workspace, preventing sidebar clutter.
3. **Conversational Prompt Grounding (R2):** Educators working on the conversational home page can instantly cite passages via the `+` attachment popover on the prompt capsule, which appends deterministic `[Pxx-Sxx]` citation tags into the prompt text.
4. **Radical Component Minimization (Rule 8):** The 4-view limit (`ChapterDashboard.tsx`, `SchemaFormModal.tsx`, `ArtifactCard.tsx`, `StoryboardGrid.tsx`) was strictly maintained by authoring navigation, view routers, and popovers inline within `ChapterDashboard.tsx`.
5. **Zero Hardcoding (Rule 7):** Tools metadata is fetched dynamically via `/api/tools`, project paths are resolved via `settings.PROJECTS_DIR`, and API calls use relative `/api/...` endpoints.
