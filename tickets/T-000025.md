## Goal
Incorporate Presenton's exact 4-step presentation pipeline into OMNIX:
1. Input / Brief Stage: Prompt textarea, slide count selector (4, 6, 8, 10, 12), chapter context.
2. Outline Generation & Review Stage: Interactive sortable outline cards, slide titles & bullet editing, add/delete slides, and outline regeneration.
3. Template & Theme Selection Stage: Visual template selection cards (Solar Obsidian, Academic Clean, Midnight Minimal, COL Blue).
4. Slide Studio Stage: Full 4-column studio workspace with 16:9 canvas, filmstrip, teacher notes, and slide co-pilot.

## Acceptance Criteria
- [x] Backend endpoint `POST /api/projects/{project_id}/slides/generate-outline` that generates structured slide outline items from chapter text and prompts.
- [x] Backend endpoint `POST /api/projects/{project_id}/slides/compile-from-outline` that compiles outline items with selected theme into presentation slides and .pptx file.
- [x] Frontend Presenton 4-step pipeline component (`PresentonSlidePipeline.tsx`) implementing exact UI styling:
  - Step 1: Input & Configuration view with slide count and language selector.
  - Step 2: Outline review view with sortable/editable items, add/remove slide actions, and floating Continue button.
  - Step 3: Template selection view with rich visual template cards.
  - Step 4: Full 4-column Slide Studio workspace with instant PPTX download and Projector mode.
- [x] Seamless integration in `ChapterDashboard`: submitting a slide prompt directly enters the pipeline at Step 2 (Outline), allowing review before rendering.
- [x] Verify clean compilation (`npm run build`) and visual screenshots for all 4 steps.
