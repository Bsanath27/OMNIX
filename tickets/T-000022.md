## Goal
Implement Presenton-inspired card layout archetypes in SlideTool, deterministic container-based python-pptx rendering, and an interactive in-browser slide editor in ArtifactCard with immediate re-compilation and download.

## Acceptance Criteria
- [x] Upgrade SlideTool (`backend/tools/slides/slide_tool.py`) data model with structured `SlideCard` and layout archetypes (`card_grid_3`, `split_comparison`, `hero_stat`, `key_takeaways`) alongside backward-compatible bullets.
- [x] Implement container-based `_build_pptx` in `slide_tool.py` drawing native rounded-rect card containers, styled header tags, text runs, and speaker notes in 16:9 widescreen slides.
- [x] Add backend slide editing and download endpoints in `backend/api/projects.py` (`PUT /api/projects/{project_id}/slides` and `GET /api/projects/{project_id}/download/{file_path:path}`).
- [x] Upgrade frontend `ArtifactCard.tsx` to render visual container cards with pedagogical badges, passage citations, speaker notes, and an inline Slide Editor with live re-compilation.
- [x] Verify clean compilation (`npm run build`), all backend test suites pass, and `python3 muontickets/mt.py validate` passes.

## Notes
Integration inspired by Presenton's card layout architecture, adapted directly into OMNIX without external Docker/database dependencies.
