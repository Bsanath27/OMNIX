## Goal
Incorporate a complete zero-login Presenton-style presentation studio workflow into OMNIX: from slide generation to 16:9 slide canvas, thumbnail filmstrip, direct inline editing, and AI-powered edit suggestions with 1-click application and instant PPTX download.

## Acceptance Criteria
- [x] Implement backend `POST /api/projects/{project_id}/slides/suggest-edits` supporting preset revision suggestions (concise, teacher tips, student-friendly, discussion prompts) and custom revision instructions with zero login/external API requirements.
- [x] Build Presenton-style 16:9 widescreen presentation canvas with responsive typography, bento cards, and layout archetypes.
- [x] Build left thumbnail filmstrip showing live mini previews of every slide, slide ordering, and Add/Duplicate/Delete slide controls.
- [x] Build direct slide editor allowing instant editing of title, subtitle, bullets, container cards, and speaker notes with immediate `PUT /api/projects/{project_id}/slides` recompilation.
- [x] Build AI Suggesting Edits drawer with preset quick actions, custom revision prompt, and 1-click "Apply Suggestion" merge.
- [x] Implement Full-Screen Classroom Projector Mode with keyboard navigation (ArrowLeft/ArrowRight, Space, Escape).
- [x] Verify clean frontend build (`npm run build`), backend tests pass, and browser visual verification.

## Notes
