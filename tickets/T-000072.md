# T-000072: Remove Forced Chapter Display from Top-Left Column & Decouple Home Creation

## Context & Problem
The homepage top-left header bar and the global navigation sidebar's left column still displayed "Physics Chapter 1", an "Active Chapter" status card, and a chapter switcher popover. Because `loadProjects()` defaulted to `data[0]`, any user landing on OMNIX was forcibly bound to the first database chapter ("Physics Chapter 1 - Light: Reflection and Refraction"), which contradicted the conversational, autonomous paradigm where users should be able to create learning materials on any topic freely without being forced into a chapter context.

## Plan & Changes
1. **Decouple Initial Project Auto-Selection (`ChapterDashboard.tsx`):**
   - In `loadProjects()`, do NOT default to `data[0]`. Only load a project if `?project=<id>` is explicitly passed in URL parameters (or if `view=studio` has slides).
   - Initialize `selectedProject` to `null` so home defaults to pure topic-first creation.
2. **Remove Top-Left Header Chapter Chip & Popover (`ChapterDashboard.tsx`):**
   - Replace the "Active Chapter Chip & Dropdown" on the top left of the header with a clean, unobtrusive system status indicator (`OMNIX Studio / Autonomous Pedagogical Studio`).
   - Remove the chapter switcher popover and click-outside listeners.
3. **Refactor Left Sidebar Column (`ChapterDashboard.tsx`):**
   - Remove the "Active Chapter" / "Select Chapter in Library" card from the bottom of the navigation sidebar.
   - Replace with an Engine Online indicator (`Presenton Engine: 5001 • v0.5.0`) alongside the theme toggle.
4. **Refactor Prompt Bar Attachment (`ChapterDashboard.tsx`):**
   - Replace the forced chapter selector button with a direct document attachment trigger (`+` button opening file input).
   - Display an attached file pill (`[Paperclip] file.ext [x]`) when a user chooses to attach a file, allowing easy removal.
   - Decouple prompt submission: user can input any topic; if a document is attached or tool is executed, an isolated project is cleanly auto-provisioned.
5. **Decouple Slide Studio Grounding Display (`PresentonSlidePipeline.tsx`):**
   - Only display the "Grounded in Chapter" banner if `project?.source_filename` is actually present (i.e. real document attached).
   - Handle standalone outline generation if `project` is null by dynamically creating a project from the topic.
