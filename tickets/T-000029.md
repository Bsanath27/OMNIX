## Goal
Allow users to click any slide visual element in OMNIX Slide Studio to search, preview, and swap diagrams or photos directly via the free image bridge without manual file uploads.

## Acceptance Criteria
- [ ] Hover overlay on slide images in `SlideStudio`: Display a "Replace Image" floating pill button when hovering over visual panels.
- [ ] Diagram & Visual Search Modal (`ImageReplacerModal.tsx`):
  - Search input pre-filled with slide topic or image prompt.
  - Tabs: "Free Scientific Diagrams (Wikimedia/DDG)" and "AI Prompt Generator".
  - Grid preview showing 6–8 candidate images with resolution and source badges.
- [ ] Instant canvas swap: Selecting an image immediately updates the slide canvas and filmstrip thumbnail in the browser state.
- [ ] Persistence: Save updated image URL/base64 into the slide presentation JSON state so subsequent exports include the replaced image.
- [ ] Keyboard accessibility: `Esc` to close modal, arrow keys to navigate preview cards, `Enter` to select.

## Implementation Plan
1. Add `onSelectImage` / `onReplaceImage` handler in `SlideStudio.tsx` and `SlideCanvas.tsx`.
2. Create `frontend/src/components/slides/ImageReplacerModal.tsx`.
3. Wire API call to `/api/slides/v2/search-images?query=...` on the OMNIX backend (connecting to the image bridge).
4. Verify image swap reflects in both 16:9 canvas and exported PPTX.
