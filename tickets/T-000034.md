## Goal
Add Presenton-style slide layout switcher toolbar (Title, 2-Column Split, 3-Card Bento, Key Metric, Bullet List) and rich inline editing in SlideStudioView.

## Context & Problem
In Presenton's presentation studio, the user can click a "Layout" button on any slide and change its visual structure on the fly (e.g., turning a 3-card grid into a 2-column comparison, or turning a text block into a prominent hero metric). 

In OMNIX's current Slide Studio, the user is locked into whatever layout was initially compiled, with no interactive layout controls.

## Acceptance Criteria
- [ ] **Slide Action Bar / Layout Switcher:** Add a toolbar above or below the 16:9 canvas with a "Change Layout" dropdown/popover:
  - Title Slide
  - 2-Column Split
  - 3-Card Grid
  - Bullet Points List
- [ ] **Live Archetype Switching:** Clicking a layout instantly updates the active slide's archetype in React state and adapts the content to fit the new layout without losing text.
- [ ] **Rich Direct Text Editing:** Allow inline editing of headings, card titles, and body paragraphs directly inside the canvas.
- [ ] **Recompile & Sync:** A "Save & Update PPTX" action that updates the backend project manifest and regenerates the downloadable `.pptx` file with the user's manual adjustments.
