# T-000073: Track All Created Projects and Deliverables in Library

## Context & Problem
Currently, the Library view only displayed manually uploaded textbook chapters. When users create presentations via the homepage prompt, Slide Studio, or the Presenton engine on port 5001, these presentations and deliverables were not automatically registered, synced, or tracked as projects in the Library. Users need the Library to act as a comprehensive hub keeping track of all projects and learning deliverables they create, allowing them to browse, inspect, launch into Slide Studio, or manage them.

## Status
**Completed & Verified**

## Solution Details
1. **Presenton Presentation Sync:**
   - In `backend/api/projects.py:list_projects`, added auto-discovery and synchronization from `http://localhost:5001/api/v1/ppt/presentation/all`.
   - Any presentation created on Presenton port 5001 is now automatically converted to a `ProjectManifest` entry with an approved `slides` artifact pointing to Presenton and saved into local data storage.
2. **Project Association in Slide Creation:**
   - In `backend/api/tools.py:/slides/create`, accepted `project_id`. When Presenton completes slide creation, the presentation artifact is automatically saved to the target project manifest. If none exists, an isolated project is cleanly provisioned for the deck.
   - In `PresentonNativeEmbed.tsx`, passed `project_id` and supported direct loading of an existing project's presentation.
3. **Project Deletion API:**
   - Added `DELETE /api/projects/{project_id}` in `backend/api/projects.py` and `deleteProject` in `frontend/src/api.ts`.
4. **Enhanced Library UI (`ChapterDashboard.tsx`):**
   - Transformed the Library into "Projects & Deliverables Library".
   - Displays all created projects with content type badges (`Slides`, `Grounded`, `Quiz`).
   - Filter chips: `All`, `Slides`, `Docs`, `Quiz`.
   - Added project deletion with confirmation.
   - For projects with presentations, added an **"Open in Slide Studio"** button and direct **"Presenton (5001)"** external link.
   - Added "Use in Prompt" button to seamlessly repurpose existing projects.
