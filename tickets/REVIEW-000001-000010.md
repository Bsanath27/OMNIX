## 4. Architectural Rules Established

1. **Zero Hardcoding Everywhere:** All ports, URLs, thresholds, and model names are driven from `Settings` (`backend/core/config.py`) or dynamic request briefs.
2. **Minimal Component Surface:** The frontend adheres strictly to the 4-view model:
   * View 1: `ChapterDashboard` (Project selector & Outline inspector)
   * View 2: `SchemaFormModal` (Universal dynamic form generated from `/api/tools` schemas)
   * View 3: `ArtifactCard` (Universal polymorphic card for Slides, Quizzes, Videos, Packages)
   * View 4: `StoryboardGrid` (Parallel scene drafts with audio duration badges)
3. **Continuous Tracking:** Every action is logged in MuonTickets comments, and every completed ticket produces an atomic git commit with ticket ID reference.
