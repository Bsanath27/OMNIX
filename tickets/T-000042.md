## Goal
Eliminate repetitive slide designs and achieve template parity with Presenton's 105 template library across 13 categories:
1. **Identify Template Gap**:
   - Presenton contains 105 slide template definitions across 13 categories (Basic, Boxes, Bullets, Card Layouts, Charts & Data, Comparison, Circles, Icons, Images, Numbers, Pyramids, Sequence, Steps) in `presentation-ai-demo/src/components/notebook/presentation/utils/templates.tsx`.
   - OMNIX previously only supported 10 basic archetypes and frequently defaulted to `card_grid_3`, resulting in repetitive decks.
2. **Implement Missing Presenton Signature Archetypes in `SlideStudioView.tsx`**:
   - `before_after`: High-contrast dual state comparison (Problem / Before state vs Transformed / After state with status pills).
   - `pros_cons`: Distinct structured evaluation (`<PROS>` with checkmark badges vs `<CONS>` with alert badges).
   - `pyramid_hierarchy`: Ascending multi-tier funnel/hierarchy pyramid (`Tier 01: Foundational` -> `Tier 02: Core` -> `Tier 03: Peak`).
   - `staircase_progression`: Ascending step elevation blocks with directional indicators (`Step 01` -> `Step 02` -> `Step 03`).
   - `snake_roadmap`: S-curve meandering milestone path with alternating node cards.
   - `circular_hub`: Central core concept disk with radial orbiting satellite cards.
   - `editorial_quote`: Oversized magazine pullquote with large quotation marks and author/citation takeaway.
   - `bento_4`: 4-card quad grid (2x2) with category badges for high-density concepts.
   - `stats_grid`: Multi-stat KPI cards with oversized metrics and progress indicator bars.
3. **Template Library Picker Modal in Studio**:
   - Add a full template browser modal (matching Presenton's `SlideTemplateModal.tsx`) categorized by layout family with live thumbnail cards and 1-click template application.
4. **LLM Slide Compilation Archetype Diversity**:
   - Update `backend/api/projects.py` to enforce strict layout diversity: no two adjacent slides can share the same archetype, and diverse archetypes (visual split, before/after, steps, pyramid, chart, pros/cons, bento) are distributed intelligently based on content structure.
5. **Visual Verification**: Zero TypeScript errors, test with live Vite dev server, and capture headless Chrome screenshots.
