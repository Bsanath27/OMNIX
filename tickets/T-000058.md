## Goal
Implement Presenton-grade interactive block slide architecture in OMNIX with in-place text editing, canvas drag-and-drop reordering, and resolve all template layout and hydration defects.

## Acceptance Criteria
- [ ] Deprecate static string rendering (`dangerouslySetInnerHTML`) in `SlideStudioView.tsx` in favor of an interactive block pipeline.
- [ ] Enable native in-place text editing for every slide text node (titles, kickers, card headers, descriptions, bullets) directly on the 1280x720 slide canvas without separate modal tabs.
- [ ] Implement per-element drag handles (`BlockDraggable` with `GripVertical`) allowing cards, columns, and blocks to be reordered dynamically with smooth drag overlays.
- [ ] Eliminate fixed-coordinate stacking so metadata and list items calculate dynamic flex offsets instead of stacking at (0, 0).
- [ ] Fix card title containers with dynamic flex spacing so wrapped headings never collide with card descriptions.
- [ ] Ensure watermark index letters are bounded and never clipped at card/container boundaries.
- [ ] 100% replace all boilerplate placeholders (e.g. "LOCATION & CONNECTIVITY", real estate copy) with curriculum topics during template hydration.
- [ ] Wire image slots properly to resolve and render valid media with graceful SVG/gradient fallbacks rather than broken `<img>` frames.
- [ ] Frontend build succeeds cleanly: `npm --prefix frontend run build`.
- [ ] Backend test suite passes: `PYTHONPATH=. .venv/bin/pytest tests/test_slides.py`.
