## Goal
Transform the OMNIX Slide Studio layout into a 1:1 Presenton Editor architecture:
1. Streamline sidebar navigation: Replace double left sidebars with Presenton's sleek, single filmstrip sidebar (`SlideSidebar`) with thumbnail previews and collapsible toggle.
2. Presenton Top Header Bar: Clean breadcrumbs, inline document title, theme picker trigger, fullscreen present mode, and export button.
3. Expanded 16:9 Presentation Stage: Give the slide stage maximum viewport breathing room, matching Presenton's centered widescreen stage with zero element clipping.
4. Presenton Floating Right Tool Dock: Sleek vertical icon pill bar (Text, Layouts, Visuals, Co-Pilot, Zoom) with slide-out Slide Co-Pilot panel.
5. Interactive Teacher Script Tray: Grounded lecture notes with LLM synthesizer and formative prompt callouts.

## Acceptance Criteria
- [x] OMNIX Studio layout matches Presenton's 3-pane architecture (Filmstrip Sidebar + Centered 16:9 Stage + Floating Tool Dock/Co-Pilot).
- [x] Double left sidebar removed so filmstrip directly previews all slides.
- [x] Floating right tool dock allows expanding/collapsing Slide Co-Pilot.
- [x] Theme switcher, 16:9 layout switcher, Present mode, and .pptx export all accessible from top header.
- [x] Zero clipping on slide cards across all screen sizes.
- [x] Frontend builds cleanly with zero errors (`npm run build`).
