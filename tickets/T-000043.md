## Goal
Transform OMNIX Studio's chrome to match Presenton's ultra-minimalist layout:
1. **Floating Vertical Tool Dock (`RightEditPanel.tsx`)**:
   - Replace the fixed 340px right sidebar with Presenton's 48px floating vertical icon dock.
   - Dock buttons: AI Co-Pilot, Templates & Layouts, Charts, Media/Assets, Theme, Speaker Notes, Zoom Controls.
2. **On-Demand Sliding Drawer (`RightPanelRenderer.tsx`)**:
   - Animated 26rem sliding drawer that opens on demand when an icon in the dock is clicked.
   - Smooth slide-in transition, search input, category headers, and auto-dismiss on canvas click.
3. **Contextual Floating Action Toolbar (`SlideElementFloatingToolbar.tsx`)**:
   - Floating pill positioned directly over whichever card or element is focused on the slide canvas.
   - Includes Quick Morph / Layout Switcher, Inline AI prompt pill ("Make punchier", "Add metrics"), Duplicate, and Delete.
4. **Header Inline Title Editor**:
   - Replace static presentation title in top bar with transparent, borderless inline editable input matching Presenton's `PresentationHeader.tsx`.
5. **Compilation Verification**:
   - Ensure `npm --prefix frontend run build` passes with zero TypeScript errors.
