## Goal
Implement Option B white-labeling and navigation lockdown so that the slide engine operates without any visible Presenton branding, routes back to OMNIX Home cleanly, and renders in the OMNIX Electric Solar Orange design system.

## Acceptance Criteria
- [x] OMNIX Solar Orange logo replaces Presenton purple logo across all template, outline, and studio screens.
- [x] OMNIX theme override stylesheet injected via Nginx remapping purple accents to `#FF5C00` and styling Back buttons as rounded pills.
- [x] External Discord, GitHub star counts, and Presenton marketing links are completely suppressed via CSS.
- [x] Client navigation interceptor script dispatches `OMNIX_NAVIGATE_BACK` on logo and template Back clicks to return to OMNIX Home.
- [x] Nginx fallback 302 redirect for `/dashboard` returning to `http://localhost:5173/`.
- [x] Frontend builds cleanly with zero TypeScript errors.

## Notes
Implemented via Nginx reverse-proxy injection (`omnix-theme-override.css`, `omnix-nav-interceptor.js`, and `sub_filter`) and asset replacement, bypassing in-memory Turbopack caching issues.
