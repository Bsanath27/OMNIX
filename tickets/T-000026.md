## Goal
Provide a 100% free, zero-key image resolution microservice supporting DuckDuckGo diagram search, Wikimedia Commons thumbnails, and Pollinations fallback to guarantee rich visuals on every presentation slide without blank placeholders or paid stock API keys.

## Context & Problem
Presenton slide generators require external image services (Pexels, Pixabay, DALL-E, Imagen). Pexels and Pixabay have paused new API key issuances, Pollinations imposed an unannounced 1-image-per-45s IP throttle causing 402/503 errors on parallel slide requests, and Gemini Imagen is unavailable on free-tier API keys. Without a bridge, generated slides displayed solid blank rectangles or missing pictures.

## Acceptance Criteria
- [x] Implement multi-tier zero-key image resolver (`scripts/pollinations_image_bridge.py`):
  - Tier 1: DuckDuckGo high-resolution scientific image and diagram search.
  - Tier 2: Wikimedia Commons thumbnail API (clean educational diagrams for biology and science).
  - Tier 3: Pollinations.ai free tier fallback.
  - Tier 4: PIL local image normalizer converting images to 1024x768 JPEG format.
- [x] Provide an OpenAI-compatible `POST /v1/images/generations` endpoint returning `b64_json` payloads for direct drop-in integration with Presenton's `openai_compatible` image provider.
- [x] Implement MD5 prompt caching in `output/image_cache/` to ensure instantaneous responses for repeated slide generations.
- [x] Verify in 7-slide real biology decks that all slides contain embedded raster graphics (`.png`/`.jpg` up to 820 KB) instead of placeholder boxes.

## Implementation Details
- **File:** `scripts/pollinations_image_bridge.py`
- **Port:** `8088`
- **Cache Location:** `output/image_cache/`
- **Validation:** Verified across both Gemini (`google_1794983581.pptx`) and OpenRouter (`openrouter_1794984004.pptx`) decks with 100% diagram population.
