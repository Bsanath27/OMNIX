## Goal
Implement native Wikimedia and DuckDuckGo diagram resolution with local disk caching and direct PPTX picture embedding to eliminate Pollinations.ai dependency.

## Acceptance Criteria
- [x] Create `backend/tools/slides/image_service.py` resolving educational diagrams via Wikimedia Commons (Tier 1), DuckDuckGo (Tier 2), and clean procedural PIL schematic fallback (Tier 3), cached in `output/image_cache/`.
- [x] Mount `/static/images` in FastAPI (`backend/main.py`) and expose `GET /api/images/resolve` endpoint for real-time resolution.
- [x] Update `backend/api/projects.py` to resolve slide images locally during generation and outline compilation.
- [x] Update `SlideStudioView.tsx` and `MediaAssetPickerDrawer.tsx` to call `/api/images/resolve` instead of hardcoded `pollinations.ai`.
- [x] Update `slide_tool.py` to embed cached local images directly into PPTX slides (`hero_visual_split`) using `slide.shapes.add_picture()`.
- [x] Verify with automated tests in `tests/test_slides.py` and ensure full test suite passes.
